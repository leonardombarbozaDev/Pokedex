# Pokédex – Álbum Pokémon

O Álbum Pokémon é um site desenvolvido pelos alunos do curso de Ciência da Computação da FIB, na disciplina de Programação para Web II.

O projeto permite visualizar, pesquisar, adicionar, editar e excluir Pokémon, utilizando a PokéAPI e o armazenamento local do navegador.

## Como executar

Acesse o site pelo GitHub Pages:

https://leonardombarbozadev.github.io/Pokedex/

O site funciona diretamente no navegador, tanto no computador quanto no celular.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PokéAPI

## Funcionalidades

- Pesquisa de Pokémon por nome, tipo e iniciais.
- Exibição de cartões com informações dos Pokémon.
- Cadastro, edição e exclusão de Pokémon.
- Armazenamento de dados no navegador.
- Tradução para português, inglês e espanhol.
- Layout adaptado para celular.
- Tratamento de erros de conexão com a API.
